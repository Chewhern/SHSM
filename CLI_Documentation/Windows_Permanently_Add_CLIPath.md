# Steps
1. Press **Windows key + R**
2. Input **sysdm.cpl**
3. Go **Advanced**
4. Click **Environment Variables...**
5. Click and edit **Path** on both **user and system variables**
6. Add the compiled CLI application path to the **Path** variable.
7. Click **OK** three times.

You can now call or use **SHSM_CLI** in terminal/command prompt or any programming languages without specifying absolute path.

Removing the CLI application path from **Path** variable also use the same steps by editing and removing it from **Path**.
