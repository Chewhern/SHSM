# Compiling details
One can refer to how **SPKI** was compiled and deployed.

However, for this CLI, kindly stop after completing compile step.

You can then copy and paste the application to a safe filesystem destination on your hosting device.

```If it's Linux (Ubuntu), I believe this might be applicable to other Linux distributions as well.
Kindly avoid any operating system or kernel based filesystem destination like '/etc'
For the destination that you choose (example '/var/somedirectoryname'),
kindly make sure the 'somedirectoryname' had read, write and execute permission given in advance
```
