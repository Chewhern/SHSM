# Types of distributed computing
In the context of distributed computing, there’re three types of applicable services.
- First being centralized cloud like the one provided by Microsoft/Amazon/Google or Baidu/Tencent/Alibaba.
- Second being proof-of-authority blockchain like the one provided by Malaysia’s Masverse or Alibaba’s own version of POA blockchain.
- Third being western public permissionless blockchain like Ethereum, Bitcoin, Solana, Arweave, XRP etc. 

Given the context of SHSM, I personally choose Arweave as its security guarantees and cost are better than that of first and second type.

Arweave uses RSA but from post-quantum cryptography perspective, it may not be suitable.

In such a regard, Arweave may not be suitable or will only last until the year of 2030 or 2032. 

In the context that Arweave can’t be used, one may need to determine either one of the following.

## Potential alternatives (POA blockchains)
Can the underlying security mechanisms be customized?

## Potential alternatives (Centralized cloud computing)
If we use centralized cloud computing, can the cybersecurity or information security aspect of them be guaranteed?

How can one ensure that the data can’t be tampered or had anti-tampering mechanisms?

These are questions need to be asked when using centralized cloud computing.
