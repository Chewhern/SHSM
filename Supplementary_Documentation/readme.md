# Supplementary Documentation

This directory contains background research and considerations that informed the design of SHSM. These documents are provided for reference.

- **AES and SM4 Hardware Vulnerabilities**: Discusses the hardware dependency of block ciphers (AES/SM4) and why stream ciphers are a safer fallback.
- **Arweave Alternatives**: Outlines the three main types of distributed computing and how Arweave fits into SHSM's architecture.
- **Historical Considerations**: References historical context (e.g., cryptographic devices from WW1/WW2) that inform the "trust" discussion.
- **Layman Explanations**: Provides non-technical explanations for cryptographic concepts:
  - Cryptographic Side-Channel Attacks
  - Physical and Virtual Theft
  - Programming Language Data Types (Mutable/Immutable)
  - Psychic Signature / All-Zero Shared Secret
- **Summary**: A consolidated overview for the 4 layman explanations and SHSM's positioning relative to them.

## A note on informed consent
The considerations behind this project are extensive, and I am aware that full informed consent is probably not achievable in practice. However, these documents are made available so that users and reviewers can at least have a clearer picture of the assumptions and constraints that shaped the design.
